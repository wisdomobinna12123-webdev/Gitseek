# GitSeek 🔍

Find any GitHub user and explore their repositories instantly.  
GitSeek is a fast, responsive PWA built with HTML, CSS, and Vanilla JavaScript.



## ✨ Features
- **Search GitHub Users** - Find any user by username
- **Profile Overview** - Avatar, bio, followers, following.
- **Repository List** - See all public repos with stars, forks, language
- **Direct Links** - Jump to GitHub profile and repos in 1 click
- **Responsive Design** - Works great on mobile, tablet, and desktop
- **Robotic UI** - Custom styling with Orbitron font for that tech vibe

## 🛠️ Tech Stack
- **HTML5** - Semantic structure
- **CSS3** - Flexbox,CSS Variables, `prefers-color-scheme`
- **JavaScript (ES6)** - Fetch API for GitHub REST API
- **GitHub API** - https://api.github.com
